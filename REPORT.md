# SRS №8 — Ограничения стека

## 1. Цель работы

Изучить работу стека памяти Arduino Uno, исследовать последствия переполнения стека при рекурсии и сравнить рекурсивный и итеративный подходы.

## 2. Теоретические сведения

Arduino Uno на базе ATmega328P имеет 2 КБ SRAM (2048 байт). SRAM используется для статических данных, динамической памяти и стека. Стек хранит данные активных вызовов функций: локальные переменные, адреса возврата и служебную информацию.

При глубокой рекурсии одновременно остаётся много активных вызовов функций. Каждый вызов занимает часть стека. Если стеку не хватает памяти, программа может зависнуть, перезапуститься или начать работать неправильно.

## 3. Предварительная оценка

Для приблизительной оценки используем формулу:

N ≈ (2048 − S − R) / F

Где S — статическая память, R — резерв памяти, F — примерный размер одного кадра стека. Это оценка, а не точное значение.

Ожидается, что при увеличении глубины рекурсии свободная память стека будет уменьшаться. При достижении предела программа может перестать нормально работать.

## 7. Инженерный вывод

В работе рассматривается влияние глубины вызовов функций на использование оперативной памяти. Рекурсия может увеличивать расход стека, потому что каждый вызов сохраняет собственные данные. Итеративный вариант позволяет выполнить большое количество повторений без постоянного увеличения глубины стека. Большие локальные массивы внутри вложенных функций также могут быстро исчерпать доступную память. В системах управления БПЛА переполнение стека может привести к сбою программы управления, поэтому важно контролировать использование памяти и предусматривать безопасное поведение при ошибках.
